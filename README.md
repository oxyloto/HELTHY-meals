# 🍱 HELTHY Meals - Concept Board

Modern, dijital konsept geliştirme workspace'i - Sağlıklı meal vending projesi için.

## 🎯 Proje Hakkında

HELTHY Meals, Türkiye'de sağlıklı beslenme sektöründe bir boşluğu doldurmayı hedefleyen yenilikçi bir meal vending konseptidir:

- **Ürün:** Vakumlu kaselerde sağlıklı kahvaltı + öğle yemeği
- **Dağıtım:** Entegre mikrodalgalı akıllı otomatlar
- **Hedef:** Çalışanlar ve öğrenciler (ofisler, üniversiteler, iş merkezleri)
- **Fark:** Sıcak/soğuk seçenek + anında ısıtma imkanı

## ✨ Board Özellikleri

Bu dijital workspace ile:

- 📝 **Not Alma:** Her bölüm için detaylı notlar oluşturun
- 🖼️ **Görsel Yönetimi:** İlham verici görselleri bir araya getirin
- ✅ **Görev Takibi:** Yapılacakları organize edin
- 🗺️ **Yol Haritası:** Projenin gelişim aşamalarını takip edin
- 💾 **Veri Saklama:** Tüm verileriniz tarayıcınızda güvenle saklanır
- 📤 **İçe/Dışa Aktarma:** Board'unuzu JSON formatında yedekleyin

## 📋 6 Ana Çalışma Alanı

1. **🍱 Menü Planlama** - Kahvaltı ve öğle yemeği çeşitleri
2. **⚙️ Operasyon** - Üretim, lojistik, raf ömrü, tedarik zinciri
3. **📍 Lokasyon Stratejisi** - İlk otomatların yerleşimi
4. **💰 Finansal Model** - Maliyet, fiyatlama, karlılık analizi
5. **🎨 Marka & Pazarlama** - İsim, kimlik, lansman stratejisi
6. **⚖️ Yasal Süreç** - Gıda izinleri, patent, şirket kurulumu

## 🚀 Başlangıç

### Gereksinimler

- Node.js 20+
- npm veya yarn

### Kurulum

\`\`\`bash
# Bağımlılıkları yükle
npm install

# Geliştirme sunucusunu başlat
npm run dev

# Tarayıcıda aç
# http://localhost:3000
\`\`\`

### Build

\`\`\`bash
# Production build
npm run build

# Production sunucusunu başlat
npm start
\`\`\`

## 💡 Kullanım İpuçları

1. **Bölümleri Keşfedin:** Her kartı tıklayarak ilgili çalışma alanına gidin
2. **Not Alın:** Fikirlerinizi, araştırmalarınızı kaydedin
3. **Görseller Ekleyin:** URL ile görsel ekleyerek mood board oluşturun
4. **Görevler Oluşturun:** Her bölüm için yapılacakları takip edin
5. **Yol Haritası:** Projenin fazlarını planlayın ve ilerleyişi izleyin
6. **Yedekleyin:** Düzenli olarak "Dışa Aktar" ile verilerinizi yedekleyin

## 🔒 Veri Güvenliği

Tüm verileriniz tarayıcınızın local storage'ında saklanır. Sunucuya hiçbir veri gönderilmez. Verilerinizi korumak için:

- Düzenli olarak dışa aktarım yapın
- JSON dosyalarını güvenli bir yerde saklayın
- Tarayıcı verilerini temizlemeden önce yedek alın
